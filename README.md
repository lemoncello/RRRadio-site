# RRRadio-site

Sitio público de **RRRadio** servido vía GitHub Pages.

## Contenido

- [`PRIVACY_POLICY.md`](PRIVACY_POLICY.md) → Política de privacidad de la app.
  - URL pública: <https://lemoncello.github.io/RRRadio-site/PRIVACY_POLICY/>

## Cómo funciona

Este repo está publicado con **GitHub Pages** (rama `main`, carpeta raíz `/`).
GitHub Pages usa Jekyll, que sirve `PRIVACY_POLICY.md` en la ruta
`/PRIVACY_POLICY/` (sin extensión).

## Actualizar la política

1. Editá `PRIVACY_POLICY.md` en este repo (o en el repo principal y copialo acá).
2. Commiteá a `main`.
3. GitHub Pages republica solo en ~1 min.
